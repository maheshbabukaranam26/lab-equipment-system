# Lab Equipments System

Open `index.html` in any browser. No install needed; data is saved in the browser (localStorage).

## Folders
- index.html: dashboard (stats, availability ring, stock by category, recent activity, overdue returns)
- pages/: equipment (cards), requests, transactions (issue and return), issues (damaged and unavailable)
- css/style.css: styles
- js/app.js: logic and sample data
- img/: optional equipment photos, named equipment-<id>.jpg
- database/lab_equipment.sql: MySQL schema for a real database backend
